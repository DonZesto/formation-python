# 🐍 Formation Python - 3 Mois

Bienvenue dans cette formation Python complète! Ce repository contient tous les cours, exercices et projets pour maîtriser Python de zéro.

## 📚 Contenu de la Formation

### **Phase 1: Fondamentaux (Semaines 1-4)**
- Variables, types de données, opérateurs
- Structures de contrôle (if/else, boucles)
- Fonctions et modules
- Gestion des erreurs

📁 Dossier: `phase-1-fondamentaux/`

### **Phase 2: Automatisation & Analyse de Données (Semaines 5-8)**
- Manipulation de fichiers (CSV, JSON)
- Expressions régulières
- Bibliothèques clés (pandas, requests)
- Mini-projets d'automatisation

📁 Dossier: `phase-2-automatisation-donnees/`

### **Phase 3: Web (Semaines 9-10)**
- Introduction à Flask/Django
- Créer une API simple
- Templates HTML/CSS basique

📁 Dossier: `phase-3-web/`

### **Phase 4: Agentic & Concepts Avancés (Semaines 11-12)**
- Programmation orientée objet (POO)
- Concepts d'agents autonomes
- Intégration avec des APIs
- Projet final intégrateur

📁 Dossier: `phase-4-agentic/`

---

## 🎯 Objectifs

- ✅ Automatiser des tâches
- ✅ Analyser des données
- ✅ Créer des applications web
- ✅ Comprendre la programmation générale
- ✅ Découvrir les agents autonomes
